# Project 1 — Retail Data Management using AWS Glue ETL Pipeline

## Objective

Implement an ETL pipeline using AWS Glue to process and integrate retail data stored in Amazon S3.

## Project Scope

The project covers the movement and transformation of retail datasets using AWS services, including:

- Amazon S3 for storing source and transformed datasets.
- AWS Glue Crawlers for automated schema discovery.
- AWS Glue Data Catalog for metadata management.
- IAM roles and permissions for service access.
- AWS Glue Studio Visual ETL for data transformation.
- Joining product and transaction datasets.
- Storing transformed output in Amazon S3.

## What It Is Used For

- Automate the extraction and processing of retail datasets.
- Discover and organize dataset schemas.
- Integrate product and transaction information.
- Transform raw data into structured output.
- Store processed datasets for subsequent analysis.
- Demonstrate a serverless cloud-based ETL workflow.

## AWS Services Used

- Amazon S3
- AWS Glue
- AWS Glue Crawlers
- AWS Glue Data Catalog
- AWS Glue Studio
- AWS IAM
